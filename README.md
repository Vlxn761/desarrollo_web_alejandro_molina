# Tarea 1 - Desarrollo Web
   
   ## Descripción
   Esta tarea incluye la implementación de una página HTML con CSS.
   
   ## Decisiones tomadas
   - La funcionalidad de agrandar la imagen fue extraída directamente desde [este tutorial]( https://www.w3schools.com/howto/howto_css_modal_images.asp)
   - Agregué comentarios en algunas funciones para mayor claridad.
   - La validación de fotos verifica que al menos uno de los inputs tenga un archivo, pero permite agregar más inputs sin enviar archivos.
   - La validación de contacto verifica que, al haber seleccionado una opción en cualquiera de los select, la URL o id respectiva cumpla con el límite de caracteres.
